# Jogo_de_Corrida_por_IA
Um carro de corrida controlado por Inteligência Artificial pela pista de corrida.

Trabalho feito na disciplina Sistemas Inteligentes, para praticar os conceitos aprendidos em sala de aula. 


Para executar, rode primeiro o treino.py, na penultima linha selecione quantas épocas deseja treinar. 
Depois execute o teste.py, ele jogará com o melhor resultado que o treino fez


Pode selecionar qual mapa você quer testar, apenas trocando entre as imagens que estão na pasta.
